# 인간GPT 팀 - 안동대학교 & 동아대학교 연합 해커톤 프로젝트

# Anu-Dong-a-Hackerton

인간GPT팀은 Python Flask와 ChatGPT API를 활용하여 C 언어의 보안적 결함을 해결하기 위한 웹 애플리케이션입니다.  
이 프로젝트는 사용자 친화적인 인터페이스와 AI 기반 분석을 통해 안전한 코딩 환경을 제공합니다.

이 프로젝트는 국립안동대학교와 동아대학교와 연합하여 만든 프로젝트입니다.

- 팀원 : 백주원 외3명

---

## 📌 프로젝트 소개

C 언어는 강력한 프로그래밍 언어지만 메모리 관리와 보안 문제에 취약합니다.  
이 프로젝트는 다음을 목표로 합니다:

- **C 코드 보안 분석**: 사용자의 C 코드에서 보안적 결함을 자동으로 탐지합니다.
- **문제 해결 제안**: ChatGPT API를 활용해 적합한 수정 방안을 제공합니다.
- **자주 일어나는 코드 예시 제공**: C언어에서 자주 발생하는 보안적결함을 예시로 알려줍니다.
- **퀴즈**: 보안퀴즈를 제공합니다.

---

## 🛠 주요 기능

1. **코드 입력 및 분석**  
   - 사용자가 C 코드를 입력하면 보안적 결함을 자동으로 분석합니다.
2. **AI 기반 수정 방안 제시**  
   - ChatGPT API를 통해 사용자가 문제를 이해하고 수정할 수 있도록 돕습니다.
3. **교육 자료 제공**  
   - 자주 발생하는 보안 문제와 해결 방법에 대한 가이드를 제공합니다.
4. **Flask 기반 웹 애플리케이션**  
   - 직관적인 사용자 인터페이스로 누구나 쉽게 접근 가능합니다.

---
